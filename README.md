# TeamFlow Fullstack

A full-stack team collaboration and task management platform built to learn modern backend development, frontend-backend integration, authentication, APIs, database management, and real-world software architecture.

This project is being developed as part of preparation for hackathons and full-stack development learning.

---

# 🚀 Project Goal

The main goal of this project is to deeply understand how modern full-stack applications work by building everything step-by-step instead of only watching tutorials.

This project focuses on:
- Backend development
- Authentication systems
- API creation
- Database integration
- Frontend ↔ Backend communication
- File uploads
- Role-based access
- Real-world project architecture
- Git & GitHub workflow

---

# 🛠️ Tech Stack

## Frontend
- React
- AI-generated UI using Antigravity
- Axios / Fetch API

## Backend
- Node.js
- Express.js

## Database
- MongoDB Atlas
- MongoDB Compass
- Mongoose

## Authentication
- JWT (JSON Web Tokens)
- bcrypt

## Version Control
- Git
- GitHub

# 🔐 Environment Variables

Sensitive data will be stored inside `.env` files and excluded from GitHub using `.gitignore`.

Examples:
- MongoDB connection string
- JWT secret
- API keys
